## 项目简介

本项目是一个基于机器学习的运动损伤风险预测系统，旨在通过分析运动员的训练数据，预测损伤风险并提供个性化的干预建议。系统集成了逻辑回归和随机森林两种分类模型，具备完整的数据挖掘流程。

### 核心功能

- **数据模拟**：生成符合真实运动场景的模拟数据集（200名运动员 × 30条记录）
- **风险预测**：基于训练时长、心率、动作类型预测损伤概率
- **干预建议**：根据预测结果生成个性化的训练干预措施
- **特征分析**：揭示影响损伤风险的关键因素
- **可视化展示**：提供混淆矩阵、特征重要性等可视化图表

---

## 功能特性

### 🏃 数据模拟模块
- 支持自定义运动员数量和记录条数
- 损伤标签基于真实运动医学规则构造：
  - 训练时长 > 120分钟：风险+20%
  - 冲刺/跳跃动作：风险+30%
  - 心率 > 170：风险+25%

### 🤖 机器学习模块
- **逻辑回归**：可解释性强，作为基准模型
- **随机森林**：非线性建模，支持特征重要性分析
- 自动划分训练/测试集（8:2），分层抽样保证类别平衡

### 📊 评估与可视化模块
- 输出分类报告（精确率、召回率、F1分数）
- 计算 AUC-ROC 指标
- 生成混淆矩阵热力图和特征重要性条形图

### 💡 干预建议模块
- 基于规则引擎生成个性化建议
- 根据风险等级（低/中低/中高/高）提供分级指导
- 支持实时预测和批量预测

## 快速开始

### 环境要求

- Python 3.9+
- 依赖包：numpy, pandas, scikit-learn, matplotlib, seaborn

### 安装依赖

```bash
pip install numpy pandas scikit-learn matplotlib seaborn
```

### 运行项目

```bash
# 克隆仓库
git clone https://github.com/asdfghjkl687/ZUOYE.git
cd ZUOYE

# 运行主程序
python 运动损伤风险预测.py
```

### 使用示例

```python
from 运动损伤风险预测 import predict_injury_risk

# 预测单个运动员的损伤风险
result = predict_injury_risk(
    duration=150,        # 训练时长（分钟）
    heart_rate=185,      # 心率（次/分钟）
    movement_type='冲刺'  # 动作类型
)

print(f"损伤概率: {result['risk_probability']}%")
print(f"风险等级: {result['risk_level']}")
print("干预建议:")
for suggestion in result['suggestions']:
    print(f"  • {suggestion}")
```

## 风险等级划分

| 风险概率 | 风险等级 | 颜色标识 | 建议动作 |
|---------|---------|---------|---------|
| < 20% | 低风险 | 🟢 绿色 | 正常训练 |

| 40%-60% | 中高风险 | 🟡 黄色 | 降低强度 |
